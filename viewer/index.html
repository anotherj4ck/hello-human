GPT-2 écrit un token à la fois

Clique sur une sphère ou une case pour plonger dans une couche · Espace : pause

Ce que tu regardes

  • Les sphères : les 12 couches de GPT-2. Chaque point est l'un des 3 072 neurones de la couche ; sa lumière est son activation réelle.
  • La colonne dorée : le mot en cours, qui traverse le réseau. Elle s'épaissit avec la taille réelle de son vecteur.
  • Les fils fins autour : les mots déjà écrits, gardés en mémoire.
  • Les filaments bleus : l'attention. Ce que le mot en cours va chercher chez les autres, juste avant chaque sphère.
  • Au-dessus des sphères : ce que le modèle prédirait s'il s'arrêtait là.
  • La traînée rose : le mot choisi repart à l'entrée. C'est la boucle.
